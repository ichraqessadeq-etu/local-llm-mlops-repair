 The issue is caused by using an outdated version of pandas (1.3.5) which does not have the `get_loc()` method with the `tolerance` parameter. To fix this, you should update the pandas version in your project.

First, update the pandas version in your `requirements.txt` file:

```
pandas==1.5.3
```

Then, run the following command to install the updated pandas version:

```
pip install -U pandas
```
