 It seems that the issue is caused by using an outdated version of MLflow (1.30.1) which does not contain the `track` function. To fix this, you should update the MLflow version in your project.

First, update the MLflow version in your `requirements.txt` file:

```
mlflow==1.21.0
```

Then, run the following command to install the updated MLflow version:

```
pip install -U mlflow
```
