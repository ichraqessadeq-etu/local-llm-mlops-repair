1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact("model.pkl", "model")
        print(f"Model with version {mlflow.get_run_id()} has been logged.")

    track("model_version", mlflow.get_run_id())
```

2. test_pipeline.py

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def setUp(self):
        self.data = load_data("data/traffic.csv")
        self.X, self.y = preprocess_data(self.data)

    def test_train_model(self):
        train_model(self.X, self.y)

if __name__ == "__main__":
    unittest.main()
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        python -m pip install -r requirements.txt

    - name: Test
      run: |
        python test_pipeline.py

    - name: Train and Log Model
      run: |
        python pipeline.py data/traffic.csv
```

In this example, I've created a simple pipeline for training a Random Forest model for congestion detection. The pipeline.py file contains functions for loading data, preprocessing data, and training the model using MLflow. The test_pipeline.py file contains a unit test for the train_model function. Lastly, the GitHub Actions YAML file defines a CI/CD pipeline that runs on every push to the main branch. It checks out the code, sets up Python 3.7, installs dependencies, runs the tests, and trains the model using MLflow.
