1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    data = data.dropna()
    return data.iloc[:, :-1], data.iloc[:, -1]

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    with mlflow.start_run():
        model.fit(X_train, y_train)
        pyfunc.log_model(model, "model", registered_model_name="congestion_detector")
        track(f"Congestion Detector Training Time", model.best_estimator_.get_params()["n_estimators"])

    return model
```

2. test_pipeline.py

```python
import unittest
from pipeline import load_data, preprocess_data, train_model
from sklearn.metrics import accuracy_score

class TestPipeline(unittest.TestCase):
    def setUp(self):
        self.data = load_data("data/traffic.csv")
        self.X, self.y = preprocess_data(self.data)
        self.X_train, self.y_train, self.X_test, self.y_test = train_test_split(self.X, self.y, test_size=0.3, random_state=42)

    def test_train_model(self):
        model = train_model(self.X_train, self.y_train)
        predictions = model.predict(self.X_test)
        expected_accuracy = accuracy_score(self.y_test, predictions)
        self.assertAlmostEqual(expected_accuracy, 0.8, delta=0.05)
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    name: Build and Test
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py

    - name: Log Artifacts
      run: |
        mlflow logs --artifact congestion_detector --outputdir .
        mlflow artifacts upload --artifact congestion_detector --dst-path .
```
