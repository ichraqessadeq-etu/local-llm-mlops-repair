1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import tracking, pyfunc, sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model = pyfunc.fit(model, X_train, y_train)
        mlflow.sklearn.log_model(model, "congestion_detector")
        tracking.log_param("n_estimators", model.n_estimators)
        tracking.log_param("max_depth", model.max_depth)
        tracking.log_param("min_samples_split", model.min_samples_split)
        tracking.log_param("min_samples_leaf", model.min_samples_leaf)
        return model
```

2. test_pipeline.py:

```python
import unittest
from pipeline import load_data, preprocess_data, train_model
from sklearn.metrics import accuracy_score

class TestPipeline(unittest.TestCase):
    def setUp(self):
        self.data = load_data("data/traffic.csv")
        self.X, self.y = preprocess_data(self.data)
        self.X_train, self.y_train, self.X_test, self.y_test = train_test_split(self.X, self.y, test_size=0.3, random_state=42)

    def test_train_model(self):
        model = train_model(self.X_train, self.y_train)
        predictions = model.predict(self.X_test)
        expected_accuracy = accuracy_score(self.y_test, predictions)
        self.assertGreaterEqual(expected_accuracy, 0.7)

if __name__ == "__main__":
    unittest.main()
```

3. .github/workflows/ci.yml:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7

      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          pip install mlflow==1.30.1 scikit-learn==1.0.2

      - name: Test pipeline
        run: pytest test_pipeline.py

      - name: Train model and log artifacts
        run: python pipeline.py

      - name: Upload artifacts
        uses: actions/upload-artifact@v2
        with:
          name: model
          path: mlruns/latest
```

This setup uses GitHub Actions to automate the CI/CD pipeline. The pipeline.py file contains functions for loading data, preprocessing data, and training the RandomForest model using MLflow. The test_pipeline.py file contains unit tests for the pipeline.py functions, and the .github/workflows/ci.yml file defines the GitHub Actions workflow that runs the tests and trains the model on every push or pull request.
