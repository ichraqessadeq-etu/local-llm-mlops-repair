1. pipeline.py

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    data = data.dropna()
    return np.array(data.drop('Congestion', axis=1)), data['Congestion']

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    with mlflow.start_run():
        model.fit(X_train, y_train)
        pyfunc.log_model(
            pyfunc.PyFuncModel.from_sklearn(model),
            artifact_path="model"
        )
        track(f"Congestion_model_version", model.version)
    return model
```

2. test_pipeline.py

```python
import unittest
from unittest.mock import patch
import pipeline
import pandas as pd

class TestPipeline(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = pd.read_csv('data/traffic.csv')
        cls.X, cls.y = pipeline.preprocess_data(cls.data)

    def test_train_model(self):
        with patch('pipeline.load_data') as mock_load_data:
            mock_load_data.return_value = self.data
            model = pipeline.train_model(self.X, self.y)
            mock_load_data.assert_called_once_with('data/traffic.csv')
            self.assertIsInstance(model, RandomForestClassifier)

if __name__ == '__main__':
    unittest.main()
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test
        run: pytest test_pipeline.py
      - name: Train and log model
        run: python pipeline.py data/traffic.csv
```

In this example, I used the `unittest` library for testing, and the `actions/checkout`, `actions/setup-python`, and `pytest` actions from GitHub Marketplace. The `requirements.txt` file should contain the required dependencies:

```
mlflow==1.30.1
scikit-learn==1.0.2
pytest
```

You can further customize the pipeline according to your specific needs and requirements.
