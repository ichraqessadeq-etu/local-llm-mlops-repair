1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")
        print(f"Model with version {mlflow.get_run_id()} has been trained.")
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        python -m pip install -r requirements.txt
        python -m pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test pipeline
      run: |
        python test_pipeline.py

    - name: Train model
      run: |
        python pipeline.py

        # Save the model artifact
        mlflow artifact add . --base-path models
        mlflow push --track-run --with-tag version=1 --with-tag environment=smart-city-traffic-management system:registry_uri/models/congestion-detector:v1
```

This setup includes a Python module `pipeline.py` with functions for loading data, preprocessing data, and training a RandomForest model using MLflow. The test file `test_pipeline.py` uses pytest and unittest.mock to test the functions in the `pipeline.py`. Lastly, the GitHub Actions YAML file sets up a CI/CD pipeline that runs the tests and trains the model on every push to the main branch. The trained model is then pushed to a specified MLflow registry.
