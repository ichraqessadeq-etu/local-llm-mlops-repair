1. pipeline.py:

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, track, pyfunc, start_run, end_run

def load_data(file_path):
    df = pd.read_csv(file_path)
    return df

def preprocess_data(data):
    data = data.dropna()  # Drop missing values
    X = data.drop('Congestion', axis=1)
    y = data['Congestion']
    return X, y

def train_model(X_train, y_train):
    with start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        track(pyfunc.fit(model, X_train, y_train), run_id="RandomForest Fit")
        log_artifact(model, artifact_path="models")

    return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          python pipeline.py --file data/traffic.csv
```

This GitHub Actions workflow will trigger on every push or pull request. It checks out the code, sets up Python 3.7, installs the dependencies from `requirements.txt`, runs the tests, and trains the model using the provided CSV file.

To create the `requirements.txt` file, you can use:

