1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import mlflow
import mlflow.sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "random-forest")

    return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Log Model
      run: python pipeline.py

    - name: Deploy
      uses: mlflow/mlflow-action@v2
      with:
        track: dev
        artifact: model
```

This pipeline uses GitHub Actions for continuous integration and continuous deployment. It checks out your code, sets up Python 3.7, installs the required dependencies, runs the tests, trains and logs the model, and deploys the model to the specified track.
