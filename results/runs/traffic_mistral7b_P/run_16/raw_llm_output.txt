1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import mlflow
import mlflow.sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "congestion_detector")

    return model
```

2. test_pipeline.py

```python
import unittest
from unittest.mock import patch
import pipeline
import pandas as pd

class TestPipeline(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = pd.read_csv("data/traffic.csv")

    def test_load_data(self):
        loaded_data = pipeline.load_data("data/traffic.csv")
        self.assertTrue(isinstance(loaded_data, pd.DataFrame))

    def test_preprocess_data(self):
        X, y = pipeline.preprocess_data(self.data)
        self.assertTrue(isinstance(X, pd.DataFrame))
        self.assertTrue(isinstance(y, pd.Series))

    @patch('pipeline.train_model')
    def test_train_model(self, mock_train_model):
        X_train, y_train = pipeline.preprocess_data(self.data)
        pipeline.train_model(X_train, y_train)
        mock_train_model.assert_called_once()

if __name__ == "__main__":
    unittest.main()
```

3. .github/workflows/ci.yml

```yaml
name: CI

on:
  push:
    branches:
      - master

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test pipeline
        run: pytest test_pipeline.py
      - name: Lint Python files
        run: flake8 .
      - name: Format Python files
        run: black .
      - name: MLflow Artifact Upload
        uses: mlflow/mlflow-docker@v1
        with:
          mlflow_tracking_uri: ${{ secrets.MLFLOW_TRACKING_URI }}
          mlflow_artifact_paths: requirements.txt,pipeline.py,test_pipeline.py
        env:
          MLFLOW_TRACKING_URI: ${{ secrets.MLFLOW_TRACKING_URI }}
```

In this example, I used the following packages:

- pandas (1.3.5)
- scikit-learn (1.0.2)
- mlflow (1.30.1)
- pytest (6.2.5)
- flake8 (5.0.4)
- black (22.3.0)

You can install these dependencies by adding them to the requirements.txt file:

