 I'll provide you with the necessary components for your request. Let's break it down into three parts: `pipeline.py`, `test_pipeline.py`, and the GitHub Actions YAML file.

1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")
        print(f"Model with version {mlflow.get_run_id()} has been trained.")
        track(f"Model trained with version {mlflow.get_run_id()}")
```

2. test_pipeline.py:

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def setUp(self):
        self.data = load_data('data/traffic.csv')
        self.X, self.y = preprocess_data(self.data)

    def test_train_model(self):
        train_model(self.X, self.y)

if __name__ == '__main__':
    unittest.main()
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        python -m pip install -r requirements.txt

    - name: Test
      run: |
        python test_pipeline.py

    - name: Train model
      run: |
        mlflow run -m pipeline.py --tracking-artifact=./
```

This setup uses GitHub Actions to run the pipeline on every push to the main branch. The pipeline uses MLflow to track the model training and log the model artifact. The test file imports every name it uses and runs the tests upon every push.

You can install the required dependencies by creating a `requirements.txt` file:
