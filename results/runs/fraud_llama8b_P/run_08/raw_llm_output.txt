Here is the code for the CI/CD pipeline:

**pipeline.py**
```python
import mlflow
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        mlflow.log_error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        X = data.drop(['Class', 'Amount'], axis=1)
        y = data['Class']
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.2, random_state=42)
        return X_train, X_test, y_train, y_test
    except Exception as e:
        mlflow.log_error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "random_forest")
        return model
    except Exception as e:
        mlflow.log_error(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import pytest
from pipeline import load_data, preprocess_data, train_model

def test_load_data():
    data = load_data("data/fraud.csv")
    assert data.shape[0] > 0

def test_preprocess_data():
    data = load_data("data/fraud.csv")
    X_train, X_test, y_train, y_test = preprocess_data(data)
    assert X_train.shape[0] > 0
    assert y_train.shape[0] > 0

def test_train_model():
    data = load_data("data/fraud.csv")
    X_train, X_test, y_train, y_test = preprocess_data(data)
    model = train_model(X_train, y_train)
    assert model is not None
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: "3.7"

      - name: Install dependencies
        run: |
          pip install mlflow scikit-learn

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train and deploy model
        run: |
          python pipeline.py
          mlflow run . --no-remote
```
This pipeline assumes that you have a `data/fraud.csv` file in your repository. The `pipeline.py` module contains the functions for loading data, preprocessing data, and training the model. The `test_pipeline.py` module contains the tests for these functions. The `.github/workflows/ci_cd.yml` file defines the CI/CD pipeline.

Note that this pipeline uses the `mlflow` package to log the model and track the experiment. The `pytest` package is used to run the tests. The pipeline assumes that you have a `main` branch in your repository, and it will run on push events to that branch.

Also, note that this pipeline uses the `scikit-learn` package version 1.0.2, which is compatible with Python 3.7 and MLflow 1.30.1.
