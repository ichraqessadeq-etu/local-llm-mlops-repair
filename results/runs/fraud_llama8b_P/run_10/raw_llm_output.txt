Here is the code for the production-ready CI/CD pipeline:

**pipeline.py**
```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow
import mlflow.sklearn

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        print(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Split data into features and target
        X = data.drop('Class', axis=1)
        y = data['Class']
        
        # Scale features using StandardScaler
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # Split data into training and testing sets
        X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.2, random_state=42)
        
        return X_train, X_test, y_train, y_test
    except Exception as e:
        print(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Train a RandomForest classifier
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log the model with MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        print(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def test_load_data(self):
        data = load_data('data/fraud.csv')
        self.assertIsNotNone(data)
    
    def test_preprocess_data(self):
        data = load_data('data/fraud.csv')
        X_train, X_test, y_train, y_test = preprocess_data(data)
        self.assertIsNotNone(X_train)
        self.assertIsNotNone(X_test)
        self.assertIsNotNone(y_train)
        self.assertIsNotNone(y_test)
    
    def test_train_model(self):
        data = load_data('data/fraud.csv')
        X_train, X_test, y_train, y_test = preprocess_data(data)
        model = train_model(X_train, y_train)
        self.assertIsNotNone(model)

if __name__ == '__main__':
    unittest.main()
```

**.github/workflows/ci_cd.yml**
```yaml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2
        
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.7'
          
      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install mlflow scikit-learn
        
      - name: Run tests
        run: |
          python -m unittest test_pipeline.py
        
      - name: Train model
        run: |
          python pipeline.py --file data/fraud.csv --output model.pkl
        
      - name: Deploy model
        uses: actions/upload-artifact@v2
        with:
          name: model.pkl
          path: model.pkl
```

This pipeline assumes that the data is stored in a CSV file named `fraud.csv` in the `data` directory. The `pipeline.py` module contains the functions for loading data, preprocessing data, and training a model. The `test_pipeline.py` module contains unit tests for these functions. The `.github/workflows/ci_cd.yml` file defines the CI/CD pipeline, which runs on every push to the `main` branch. The pipeline checks out the code, sets up Python, installs dependencies, runs tests, trains a model, and deploys the model as an artifact.
