### 1. Python Module `pipeline.py`

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score, classification_report
import mlflow
import mlflow.sklearn

def load_data(file_path):
    """
    Load data from a CSV file.
    
    Args:
        file_path (str): Path to the CSV file.
    
    Returns:
        pd.DataFrame: Loaded data.
    """
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        raise Exception(f"Failed to load data: {e}")

def preprocess_data(data):
    """
    Preprocess data by separating features and target.
    
    Args:
        data (pd.DataFrame): Input data.
    
    Returns:
        tuple: Features (X) and target (y).
    """
    try:
        X = data.drop(columns=['Class'])
        y = data['Class']
        return X, y
    except Exception as e:
        raise Exception(f"Failed to preprocess data: {e}")

def train_model(X_train, y_train):
    """
    Train a RandomForestClassifier model.
    
    Args:
        X_train (pd.DataFrame): Training features.
        y_train (pd.Series): Training target.
    
    Returns:
        RandomForestClassifier: Trained model.
    """
    try:
        with mlflow.start_run():
            mlflow.log_param("model", "RandomForestClassifier")
            model = RandomForestClassifier(n_estimators=100, random_state=42)
            model.fit(X_train, y_train)
            mlflow.sklearn.log_model(model, "model")
            mlflow.log_metric("accuracy", accuracy_score(y_train, model.predict(X_train)))
            mlflow.log_artifact("data/fraud.csv", artifact_path="data")
            return model
    except Exception as e:
        raise Exception(f"Failed to train model: {e}")
```

### 3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline for Fraud Detection

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python 3.8
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pandas scikit-learn mlflow pytest

    - name: Run tests
      run: pytest test_pipeline.py

    - name: Train model and log to MLflow
      run: |
        python pipeline.py
```

### Explanation

1. **Python Module `pipeline.py`**:
   - `load_data`: Loads data from a CSV file.
   - `preprocess_data`: Separates features and target from the data.
   - `train_model`: Trains a RandomForestClassifier model and logs it to MLflow.

2. **Pytest File `test_pipeline.py`**:
   - Tests the `load_data`, `preprocess_data`, and `train_model` functions to ensure they work correctly.

3. **GitHub Actions YAML**:
   - Sets up a CI/CD pipeline that runs on every push to the `main` branch.
   - Checks out the code, sets up Python 3.8, installs dependencies, runs tests, and trains the model and logs it to MLflow.
