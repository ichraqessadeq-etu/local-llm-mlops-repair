3. GitHub Actions YAML:

```yaml
name: CI/CD for Traffic Prediction

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Python
        uses: actions/setup-python@v2
        with:
          python-version: 3.8
      - name: Install dependencies
        run: |
          pip install pandas mlflow pytest
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          mlflow run . --track-run
```

This pipeline uses MLflow for model training, tracking, and logging. It also uses pytest for unit testing. The GitHub Actions workflow is triggered on push and pull requests, sets up Python, installs dependencies, runs tests, and trains the model using MLflow.
