3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow sklearn

    - name: Test Pipeline
      run: |
        python test_pipeline.py

    - name: Train and Log Model
      run: |
        python pipeline.py data/traffic.csv
```

This setup includes a Python module (pipeline.py) with functions to load data, preprocess data, and train a model using MLflow. It also includes a pytest file (test_pipeline.py) for testing the pipeline functions. Lastly, it includes a GitHub Actions workflow (.github/workflows/ci-cd.yml) that runs the tests and trains the model on every push to the main branch.
