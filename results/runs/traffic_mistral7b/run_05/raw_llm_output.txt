3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test Pipeline
      run: pytest test_pipeline.py

    - name: Train and Log Model
      run: python pipeline.py

    - name: Upload Model
      uses: mlflow/mlflow-github-action@v1
      with:
        track: dev
        artifact: model
```

In this example, I've used MLflow for model training and logging, and pytest for testing. The GitHub Actions workflow is set up to trigger on pushes to the main branch. It installs dependencies, runs tests, trains the model, logs it to MLflow, and then uploads the model as an artifact.

Please note that you'll need to create a requirements.txt file to list your project's dependencies. Also, you should adjust the preprocessing and testing steps according to your specific needs.

Lastly, don't forget to initialize your GitHub repository with MLflow's tracking server URL:

```bash
mlflow init --tracking-uri mlflow.local
```

For using MLflow with a remote tracking server, please refer to the official MLflow documentation.
