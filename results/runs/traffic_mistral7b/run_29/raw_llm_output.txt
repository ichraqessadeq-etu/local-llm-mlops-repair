3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.8
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py --file data/traffic.csv

    - name: Upload model
      uses: mlflow/mlflow-github-action@v2
      with:
        track: dev
        artifact_path: ./mlruns
```

This pipeline loads data, preprocesses it, trains a model using Random Forest Classifier, and tests the functions using pytest. The trained model is tracked using MLflow and uploaded to GitHub when a push event occurs on the 'main' branch. You can adjust the configuration as needed for your specific use case.
