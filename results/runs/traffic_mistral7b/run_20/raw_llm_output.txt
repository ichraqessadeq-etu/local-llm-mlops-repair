3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python environment
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow sklearn

    - name: Test
      run: |
        python test_pipeline.py

    - name: Train and log model
      run: |
        python pipeline.py data/traffic.csv
```

This setup includes a Python module `pipeline.py` with functions to load data, preprocess data, and train a model using MLflow. The test suite `test_pipeline.py` tests the functionality of the pipeline. The GitHub Actions workflow runs the tests on every push or pull request and trains and logs the model.
