3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow sklearn

    - name: Test and Train
      run: |
        python test_pipeline.py
        python pipeline.py

    - name: Upload artifacts
      uses: actions/upload-artifact@v2
      with:
        name: model
        path: mlruns/
```

This setup uses MLflow to track the model and its parameters, and GitHub Actions for the CI/CD pipeline. The pipeline.py file loads the data, preprocesses it, trains a RandomForest model, and logs the model using MLflow. The test_pipeline.py file contains unit tests for the pipeline.py functions. The GitHub Actions YAML file sets up the CI/CD pipeline to run on every push or pull request, installs the necessary dependencies, runs the tests and trains the model, and uploads the model as an artifact.
