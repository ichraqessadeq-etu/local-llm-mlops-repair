3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py

    - name: Upload Model
      uses: mlflow/mlflow-action@v2
      with:
        track: dev
        artifact_path: models
```

This pipeline uses MLflow for model training and tracking, pytest for unit testing, and GitHub Actions for continuous integration and deployment. The pipeline loads data, preprocesses it, trains a RandomForest model, and tests the pipeline functions. The trained model is then uploaded to MLflow.
