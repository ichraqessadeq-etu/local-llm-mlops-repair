3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: 3.8
      - name: Install dependencies
        run: |
          pip install pandas mlflow pytest
      - name: Test
        run: pytest test_pipeline.py
      - name: Train and Log Model
        run: python pipeline.py
```

This setup uses MLflow for model training and logging, pytest for testing, and GitHub Actions for CI/CD. The pipeline.py file contains functions for loading data, preprocessing data, and training a RandomForest model. The test_pipeline.py file contains unit tests for the pipeline functions. The GitHub Actions workflow runs tests on every push or pull request and trains and logs the model if the tests pass.
