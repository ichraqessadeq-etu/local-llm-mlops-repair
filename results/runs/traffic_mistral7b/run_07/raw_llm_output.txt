```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
import mlflow
import mlflow.sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Preprocessing steps like filling missing values, encoding categorical variables, etc.
    # For simplicity, I'm assuming no missing values and no encoding is needed.
    return data['temp'], data['rain_1h'], data['snow_1h'], data['clouds_all'], data['weather_main'], data['IsHoliday'], data['Hour'], data['DayOfWeek'], data['Month'], data['Congestion']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "random-forest")
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Setup Python environment
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        python -m pip install -r requirements.txt

    - name: Test pipeline
      run: |
        python test_pipeline.py

    - name: Train and log model
      run: |
        python pipeline.py
        mlflow login --host $MLFLOW_TRACKING_URI
        mlflow push artifact . -f model
```

In the above example, I've used MLflow for model training and logging. The GitHub Actions workflow is triggered on push and pull requests. It checks out the code, sets up a Python environment, installs dependencies, runs the tests, trains the model, logs it to MLflow, and pushes the model artifact.

You'll need to create a `requirements.txt` file to list your project's dependencies. Also, don't forget to set the `MLFLOW_TRACKING_URI` environment variable in your GitHub repository settings to point to your MLflow tracking server.
