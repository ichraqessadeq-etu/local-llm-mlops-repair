3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2
    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8
    - name: Install dependencies
      run: |
        pip install -r requirements.txt
    - name: Test
      run: pytest test_pipeline.py
    - name: Train and Log Model
      run: python pipeline.py
    - name: Deploy Model
      uses: mlflow/mlflow-action@v2
      with:
        track: production
        artifact_path: ./mlruns
```

This example assumes you have a requirements.txt file listing your project's dependencies. It also uses GitHub Actions for the CI/CD pipeline, MLflow for model training and logging, and pytest for testing. You'll need to adjust the code and configuration to fit your specific needs.
