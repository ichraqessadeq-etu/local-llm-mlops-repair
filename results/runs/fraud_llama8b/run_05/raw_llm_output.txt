Here is the code for the production-ready CI/CD pipeline:

**pipeline.py**
```python
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow
import logging

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        logging.error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Split data into features and target
        X = data.drop('Class', axis=1)
        y = data['Class']
        
        # Scale features using StandardScaler
        scaler = StandardScaler()
        X_scaled = scaler.fit_transform(X)
        
        # Split data into training and testing sets
        X_train, X_test, y_train, y_test = train_test_split(X_scaled, y, test_size=0.2, random_state=42)
        
        return X_train, X_test, y_train, y_test
    except Exception as e:
        logging.error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Create and train a RandomForestClassifier model
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log the model with MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        logging.error(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import pytest
from pipeline import load_data, preprocess_data, train_model

def test_load_data():
    data = load_data('data/fraud.csv')
    assert data is not None

def test_preprocess_data():
    data = load_data('data/fraud.csv')
    X_train, X_test, y_train, y_test = preprocess_data(data)
    assert X_train is not None and X_test is not None and y_train is not None and y_test is not None

def test_train_model():
    data = load_data('data/fraud.csv')
    X_train, X_test, y_train, y_test = preprocess_data(data)
    model = train_model(X_train, y_train)
    assert model is not None
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.8'

      - name: Install dependencies
        run: |
          python -m pip install --upgrade pip
          pip install mlflow scikit-learn pandas numpy

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train and log model
        run: |
          mlflow ui
          python pipeline.py train_model data/fraud.csv

      - name: Deploy model
        uses: actions/deploy@v1
        with:
          provider: AWS
          region: us-west-2
          bucket: my-bucket
          model-name: random_forest
```

This pipeline assumes that you have the `mlflow` and `scikit-learn` libraries installed. The `test_pipeline.py` file contains three tests: `test_load_data`, `test_preprocess_data`, and `test_train_model`. The `ci_cd.yml` file defines a GitHub Actions workflow that runs the tests, trains the model, and deploys it to AWS S3.

Note that you'll need to replace `my-bucket` with your actual S3 bucket name and `us-west-2` with your actual AWS region. Also, make sure to install the `actions/deploy` action by running `pip install actions/deploy`.
