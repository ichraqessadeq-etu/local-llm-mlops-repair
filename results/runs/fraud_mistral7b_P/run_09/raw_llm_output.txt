1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Class', axis=1), data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        track(f"Model trained with {len(X_train)} training samples")
        return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          mlflow run --python pipeline.py --track-runs-as-experiments --param data=data/fraud.csv
```

In this example, I've created a simple pipeline for training a RandomForest model with the given data and used GitHub Actions to set up a CI/CD pipeline. The test_pipeline.py file contains unit tests for the pipeline.py module. The GitHub Actions YAML file sets up a workflow that runs on every push or pull request, checks out the code, sets up Python 3.7, installs dependencies, runs the tests, and trains the model using MLflow.
