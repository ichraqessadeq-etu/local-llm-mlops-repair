1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Amount', axis=1), data['Amount']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact("data/fraud.csv", "data")
        track(f"Training score: {model.score(X_train, y_train)}")
```

2. test_pipeline.py:

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          python pipeline.py
      - name: Upload artifacts
        uses: mlflow/mlflow-github-action@v1
        with:
          track-runs-on-push: true
          artifact-path: artifacts
          artifact-name: artifacts
```

This setup uses GitHub Actions to trigger the pipeline on every push to the main branch. It installs the required dependencies, runs the tests, trains the model, and uploads the artifacts using MLflow.

Make sure to create a `requirements.txt` file containing the necessary dependencies:

```
mlflow==1.30.1
pandas==1.3.5
scikit-learn==1.0.2
pytest==6.2.5
```
