1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Class', axis=1), data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "model")
        mlflow.log_artifact("data/fraud.csv", "data")
        pyfunc.log_model(model, "scikit_learn_model")
        track(f"Training Accuracy: {model.score(X_train, y_train)}")
        track(f"Testing Accuracy: {model.score(X_test, y_test)}")
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py
```

This setup uses GitHub Actions for the CI/CD pipeline, tests the pipeline using pytest, and trains the Random Forest model with MLflow. Make sure to create a `requirements.txt` file to list the necessary dependencies.
