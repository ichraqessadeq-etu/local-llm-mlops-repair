1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Amount', axis=1), data['Amount']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")
        print(f"Model with version {mlflow.get_run_id()} has been trained.")
```

2. test_pipeline.py

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def setUp(self):
        self.data = load_data('data/fraud.csv')
        self.X, self.y = preprocess_data(self.data)

    def test_train_model(self):
        train_model(self.X, self.y)

if __name__ == '__main__':
    unittest.main()
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          python pipeline.py
      - name: Upload artifacts
        uses: mlflow/mlflow-github-action@v1
        with:
          track_run: true
          mlflow_artifacts: pipeline.py test_pipeline.py
```

In this example, I've used the `mlflow` package to track runs, log models, and upload artifacts. The test file `test_pipeline.py` imports every name it uses and runs the tests when the GitHub Actions pipeline is triggered. The target environment is Python 3.7 with `MLflow 1.30.1` and `scikit-learn 1.0.2`.
