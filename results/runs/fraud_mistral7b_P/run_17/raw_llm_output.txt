1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Class', axis=1), data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        pyfunc.log_model(model, "model", registered_model_name="random_forest")
        track(f"Model Training Time", mlflow.get_run().info.start_time)

    return model
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2
    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7
    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install scikit-learn==1.0.2 mlflow==1.30.1
    - name: Test and Train
      run: |
        python -m pytest test_pipeline.py
        python pipeline.py
        mlflow login --set-default-artifact-repository https://artifact.mlflow.org/v1/artifact/<your-account-id>
        mlflow push --track run --tag "branch=main" .
```
