1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Amount', axis=1), data['Amount']

def train_model(X_train, y_train):
    with mlflow.start_run():
        track('experiment_name', 'Fraud Detection')
        track('run_id', f'{str(hash(str(X_train)))[:8]}')

        model = RandomForestClassifier()
        model.fit(X_train, y_train)

        mlflow.pyfunc.log_model(
            pyfunc.DistributedModel.from_flask(model),
            artifact_path='model'
        )

        print(f'Model trained with accuracy: {model.score(X_train, y_train)}')
```

3. GitHub Actions YAML

```yaml
name: CI/CD for Fraud Detection

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py

    - name: Log Artifacts
      run: |
        mlflow logs --artifact . --output-dir=mlruns
```
