**pipeline.py**

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import pyfunc, track, active_run

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data[['Time', 'V1', 'V2', 'V3', 'V4', 'V5', 'V6', 'V7', 'V8', 'V9', 'V10', 'V11', 'V12', 'V13', 'V14', 'V15', 'V16', 'V17', 'V18', 'V19', 'V20', 'V21', 'V22', 'V23', 'V24', 'V25', 'V26', 'V27', 'V28', 'Amount']], data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run(run_name="RandomForest-Fraud-Detector"):
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(pyfunc.DistributedLogModel.from_sklearn(model), "model")
        track(active_run().info.run_id)
    return model
```

**GitHub Actions YAML**

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2
    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7
    - name: Install dependencies
      run: |
        python -m pip install -U mlflow scikit-learn pytest
    - name: Test
      run: |
        python test_pipeline.py
```

This setup uses GitHub Actions for the CI/CD pipeline, and it checks the code on every push to the main branch. The pipeline.py file contains functions for loading data, preprocessing data, and training a RandomForest model using MLflow for model logging. The test_pipeline.py file contains unit tests for the pipeline.py functions. The test file imports every name it uses, and it uses pytest for running the tests.
