1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Class', axis=1), data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "model")
        mlflow.log_param("num_trees", model.n_estimators)
        mlflow.log_artifact("model.pkl", "model")
        pyfunc.log_model(model, artifact_path="model")
        track(model.score(X_train, y_train))
```

2. test_pipeline.py:

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = load_data('data/fraud.csv')
        cls.X, cls.y = preprocess_data(cls.data)

    def test_train_model(self):
        X_train, y_train, _, _ = train_test_split(self.X, self.y, test_size=0.2, random_state=42)
        train_model(X_train, y_train)

if __name__ == '__main__':
    unittest.main()
```

3. GitHub Actions YAML:

```yaml
name: CI/CD for Fraud Detection System

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train Model
        run: |
          pytest test_pipeline.py
          python pipeline.py
```
