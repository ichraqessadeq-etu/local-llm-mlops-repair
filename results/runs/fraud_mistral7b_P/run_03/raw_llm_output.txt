1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import mlflow
import mlflow.sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Preprocessing steps like filling missing values, encoding categorical variables, etc.
    # For simplicity, I'm assuming there are no missing values and no categorical variables.
    # Adjust the preprocessing steps according to your actual dataset.
    return data['X'], data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)

        # Log the model to MLflow
        mlflow.sklearn.log_model(model, "random-forest")

        # Log the parameters of the model to MLflow
        mlflow.log_param("n_estimators", model.n_estimators)
        mlflow.log_param("max_depth", model.max_depth)
        mlflow.log_param("min_samples_split", model.min_samples_split)
        mlflow.log_param("min_samples_leaf", model.min_samples_leaf)
        mlflow.log_param("random_state", model.random_state)

    return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD for Fraud Detection System

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test Pipeline
      run: pytest test_pipeline.py

    - name: Train Model
      run: python pipeline.py

    - name: Upload Model to MLflow
      uses: mlflow/mlflow-action@v2
      with:
        track: dev
        artifact: model
        mlflow-version: 1.30.1
```

This setup includes a Python module `pipeline.py` with functions for loading data, preprocessing data, and training a RandomForest model. It also includes a test file `test_pipeline.py` using pytest for testing the pipeline. Lastly, it includes a GitHub Actions workflow for building, testing, and training the model. The workflow uses MLflow to track and manage the model artifacts.
