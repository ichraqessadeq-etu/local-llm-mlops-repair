1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Amount', axis=1), data['Amount']

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    with mlflow.start_run(run_name='Fraud Detection'):
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")
        print(f"Model training completed with tracking run id: {tracking_run_id}")

    return model
```

2. test_pipeline.py

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = load_data('data/fraud.csv')

    def test_load_data(self):
        self.assertIsInstance(self.data, pd.DataFrame)

    def test_preprocess_data(self):
        X, y = preprocess_data(self.data)
        self.assertIsInstance(X, pd.DataFrame)
        self.assertIsInstance(y, pd.Series)

    def test_train_model(self):
        X_train, y_train = train_test_split(self.data.drop('Amount', axis=1), self.data['Amount'], test_size=0.2, random_state=42)
        model = train_model(X_train, y_train)
        self.assertIsInstance(model, RandomForestClassifier)

if __name__ == '__main__':
    unittest.main()
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train Model
        run: |
          pytest test_pipeline.py
          python pipeline.py
          mlflow run --track-runs --python pipeline.py
```

In this example, I used the `mlflow` package to track the model training runs and log the model artifacts. The test file `test_pipeline.py` imports every name it uses and runs tests for each function. The GitHub Actions YAML file sets up a CI/CD pipeline that runs on every push or pull request, tests the code, trains the model, and logs the model artifacts using MLflow.

To use this setup, make sure to create a `requirements.txt` file containing the necessary dependencies:

```
mlflow==1.30.1
scikit-learn==1.0.2
pytest==6.2.5
```

You can then push the code to GitHub and configure GitHub Actions to run the CI/CD pipeline.
