1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Amount'].values

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")
        print(f"Model with version {mlflow.get_run_id()} has been logged.")

    track(f"Model Training Time", mlflow.get_run().info.start_time)
```

2. test_pipeline.py:

```python

class TestPipeline(unittest.TestCase):

    def test_train_model(self):
        X_train, X_test, y_train, y_test = train_test_split(self.X, self.y, test_size=0.3, random_state=42)
        train_model(X_train, y_train)

if __name__ == "__main__":
    unittest.main()
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          python pipeline.py
      - name: Upload artifacts
        uses: mlflow/mlflow-github-action@v1
        with:
          track_runs: true
          artifact_paths:
            - models
```

Make sure to create a `requirements.txt` file and include the following dependencies:

```
mlflow==1.30.1
scikit-learn==1.0.2
pandas==1.3.5
pytest==6.2.5
```
