1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, tracking

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Anomaly']

def train_model(X_train, y_train):
    with mlflow.start_run():
        mlflow_run_id = mlflow.active_run().info.run_id
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        pyfunc.log_model(
            model, artifact_path="model", registered_model_name="AnomalyDetector"
        )
        log_artifact(artifact="model.pkl", local_path="model")
        print(f"Model saved with run id: {mlflow_run_id}")
        return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: |
        python test_pipeline.py

    - name: Train and log model
      run: |
        mlflow run . --python pipeline.py
```
