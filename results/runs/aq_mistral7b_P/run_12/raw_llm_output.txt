**2. test_pipeline.py**

```python
import unittest
from pipeline import load_data, preprocess_data, train_model, save_model
from sklearn.metrics import accuracy_score

class TestPipeline(unittest.TestCase):
    @classmethod
    def setUpClass(cls):
        cls.data = load_data('data/air_quality.csv')
        cls.X, cls.y = preprocess_data(cls.data)

    def test_train_model(self):
        X_train, X_test, y_train, y_test = train_test_split(self.X, self.y, test_size=0.3, random_state=42)
        model = train_model(X_train, y_train)
        y_pred = model.predict(X_test)
        assert accuracy_score(y_test, y_pred) > 0.8

    def test_save_model(self):
        with pyfunc.local_context() as mlflow_run:
            mlflow.start_run(run_name="anomaly_detector")
            model = train_model(self.X, self.y)
            save_model(model, mlflow_run.info.run_id)
            artifact_path = mlflow.get_artifact_uri("models/{}".format(mlflow_run.info.run_id))
            assert artifact_path is not None
```

**3. GitHub Actions YAML**

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest --cov=pipeline tests
          python pipeline.py --tracking-artifact=models
```

This setup uses GitHub Actions to run the CI/CD pipeline on every push and pull request. It checks out the code, sets up Python 3.7, installs dependencies from `requirements.txt`, runs the tests, and trains the model using MLflow. The trained model is saved as an artifact in MLflow.

Make sure to create a `requirements.txt` file containing the necessary dependencies:

```
mlflow==1.30.1
pandas==1.3.5
scikit-learn==1.0.2
pytest==6.2.5
```

To run the test locally, you can use:

```bash
pip install -r requirements.txt
pytest tests
```
