1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, tracking, pyfunc

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Anomaly', axis=1), data['Anomaly']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.log_artifact(artifact=model, artifact_path="models")
        mlflow.pyfunc.log_model(pyfunc.get_model(model), "models")
        tracking.log_param("num_trees", model.n_estimators)
        tracking.log_param("max_depth", model.max_depth)
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test
        run: pytest test_pipeline.py
      - name: Train and log model
        run: python pipeline.py
        env:
          MLflow_tracking_uri: ${{ secrets.MLFLOW_TRACKING_URI }}
```

In this example, I've used `pytest` for testing, and the GitHub Actions workflow triggers on push events and pull requests. The pipeline loads data, preprocesses it, trains a RandomForest model, and logs the model using MLflow. The test file `test_pipeline.py` imports all the necessary functions and tests the `train_model` function.
