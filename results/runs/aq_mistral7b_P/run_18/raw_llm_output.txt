3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test
        run: pytest test_pipeline.py
      - name: Train and Log Model
        run: python pipeline.py
      - name: Upload Artifacts
        uses: mlflow/mlflow-github-action@v1
        with:
          track_runs: true
          artifact_paths:
            - model
```

This pipeline uses MLflow for model training, logging, and tracking, and pytest for testing. The target environment is Python 3.7 with MLflow 1.30.1 and scikit-learn 1.0.2. The pipeline uses only functions that exist in these versions.
