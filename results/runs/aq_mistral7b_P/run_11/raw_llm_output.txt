3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          python -m pip install -r requirements.txt
      - name: Test
        run: |
          python test_pipeline.py
      - name: Train and Log Model
        run: |
          python pipeline.py data/air_quality.csv
```

This setup uses GitHub Actions for CI/CD, tests the pipeline with pytest, and logs the model using MLflow. The target environment is Python 3.7 with MLflow 1.30.1 and scikit-learn 1.0.2. The test file imports every name it uses, and the pipeline functions only use functions that exist in these versions.
