1. pipeline.py:

```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, track, pyfunc, save_model, load_model

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return np.array(data.drop('Anomaly', axis=1)), data['Anomaly']

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    model.fit(X_train, y_train)
    track(f"Model Training Time", model.score(X_train, y_train))
    return model

def save_model_and_data(model, artifact_path):
    log_artifact(artifact_path + "/model", model)
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest tests/test_pipeline.py
          python pipeline.py --mlflow-tracking-uri mlflow_tracking_uri --artifact-path artifacts
      - name: Save artifacts
        uses: actions/upload-artifact@v2
        with:
          name: artifacts
          path: artifacts
```

In this example, I've assumed that you have a `requirements.txt` file containing the required dependencies:

```
mlflow==1.30.1
scikit-learn==1.0.2
pandas==1.3.5
numpy==1.21.5
```

Make sure to replace `mlflow_tracking_uri` with your MLflow tracking URI in the GitHub Actions YAML.

This pipeline uses MLflow for model tracking and artifact management, and pytest for testing. It also includes error handling through the use of assertions in the test file and MLflow's tracking functionality in the pipeline.py file.
