3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test and Train
        run: |
          pytest test_pipeline.py
          python pipeline.py
```

In this example, I've used the `pytest` command for testing and `pip` to install dependencies. You can manage your dependencies in a `requirements.txt` file. The GitHub Actions workflow runs on every push to the main branch. It checks out the code, sets up Python 3.7, installs dependencies, runs tests, and trains the model.

Please note that this is a basic example and you may need to adjust it according to your specific needs, such as adding more tests, error handling, and optimizing the model. Also, make sure to install the required packages (scikit-learn, MLflow) in your environment before running the pipeline.py script.

Lastly, don't forget to create a `requirements.txt` file with the following content:

```
mlflow==1.30.1
scikit-learn==1.0.2
pandas
pytest
```
