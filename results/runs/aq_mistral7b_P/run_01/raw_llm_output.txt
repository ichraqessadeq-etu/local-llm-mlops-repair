3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install mlflow==1.30.1 scikit-learn==1.0.2 pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: MLflow Model Training
      run: python pipeline.py

    - name: Push MLflow artifacts to GitHub
      uses: mlabouardy/action-mlflow-artifacts@master
      with:
        artifact_name: mlflow_artifacts
        mlflow_track_run_id: ${{ github.run_id }}
```

This setup will create a CI/CD pipeline that runs on every push or pull request. It tests the pipeline using pytest, trains the RandomForest model, and pushes the trained model as an MLflow artifact to GitHub.
