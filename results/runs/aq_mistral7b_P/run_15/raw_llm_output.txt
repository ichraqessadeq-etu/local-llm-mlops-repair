1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, tracking

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data.drop('Anomaly', axis=1), data['Anomaly']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        pyfunc.log_model(model, "anomaly_detector")
        run_id = tracking.active_run().info.run_id
        log_artifact(f"anomaly_detector_{run_id}.pkl", "anomaly_detector")
        return model
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test
        run: |
          python test_pipeline.py
      - name: Train Model
        run: |
          mlflow run . --tracking-artifact . --python pipeline.py
```

This setup uses GitHub Actions to trigger the pipeline on every push or pull request. It checks out the code, sets up Python 3.7, installs dependencies, runs the tests, and trains the model using MLflow. The trained model is saved as an artifact and can be used for deployment.
