3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install mlflow scikit-learn pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and log model
      run: python pipeline.py

    - name: Log artifacts
      run: |
        mlflow logs --artifact air_quality_model

```

This example uses GitHub Actions to automate the CI/CD pipeline. It checks out the code, sets up Python 3.7, installs the required dependencies, runs the tests, trains the model, and logs the model as an artifact. The test file imports every name it uses, and error handling is implicit in the used libraries.
