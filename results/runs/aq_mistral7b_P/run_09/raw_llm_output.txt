1. pipeline.py:

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    return data, data['Anomaly']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "model")
        track(f"Model Training Time", mlflow.get_run().info.start_time)
        return model
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          python -m pip install -r requirements.txt
      - name: Test and Train
        run: |
          python pipeline.py
          pytest test_pipeline.py
      - name: Upload artifacts
        uses: mlflow/mlflow-github-action@v1
        with:
          track_runs: true
          artifacts:
            - "model"
```

This setup uses GitHub Actions for continuous integration and deployment. The pipeline.py file contains functions for loading data, preprocessing data, and training the Random Forest model using MLflow. The test_pipeline.py file contains unit tests for the pipeline.py functions. The GitHub Actions YAML file sets up the CI/CD pipeline that runs on every push or pull request, installs dependencies, tests the pipeline, trains the model, and uploads the trained model as an artifact.
