3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python 3.7
        uses: actions/setup-python@v2
        with:
          python-version: 3.7
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
      - name: Test pipeline
        run: |
          pytest test_pipeline.py
      - name: Train and log model
        run: |
          python pipeline.py data/air_quality.csv
```

This setup uses GitHub Actions to run the pipeline on every push and pull request. It checks out the code, sets up Python 3.7, installs dependencies from `requirements.txt`, runs the tests, and trains and logs the model.

You'll need to create a `requirements.txt` file containing:

```
mlflow==1.30.1
scikit-learn==1.0.2
pandas
pytest
```

Make sure to create the `requirements.txt` file in your project's root directory.
