1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import mlflow

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    X = data.drop('Anomaly', axis=1)
    y = data['Anomaly']
    return X, y

def train_model(X_train, y_train):
    with mlflow.start_run():
        mlflow.set_tag('target', 'anomaly_detector')
        mlflow.log_artifacts({'initial_data': data.to_csv()})

        model = RandomForestClassifier()
        model.fit(X_train, y_train)

        mlflow.sklearn.log_model(model, 'anomaly_detector')
```

3. GitHub Actions YAML

```yaml
name: CI/CD for Smart City Air Quality System

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install mlflow scikit-learn pandas pytest

    - name: Test pipeline
      run: pytest test_pipeline.py

    - name: Train model
      run: python pipeline.py

    - name: Upload artifacts
      uses: mlflow/mlflow-action@v2
      with:
        track: dev
        artifact_path: .
```

This setup uses GitHub Actions to automatically test and train the model whenever changes are pushed to the `main` branch. The `test_pipeline.py` file contains a test for the `train_model` function, and the GitHub Actions YAML file sets up the environment, runs the tests, and trains the model using MLflow.
