3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7
    - name: Install dependencies
      run: |
        python -m pip install -r requirements.txt
    - name: Test and Train
      run: |
        python pipeline.py
        python test_pipeline.py
    - name: Upload artifacts
      uses: mlflow/mlflow-github-action@v1
      with:
        track-run: true
        artifact: artifacts
```

This setup uses GitHub Actions to run the pipeline on each push to the main branch. It checks out the code, sets up Python 3.7, installs the dependencies, runs the pipeline, and then uploads the artifacts using the mlflow GitHub action. The test_pipeline.py file tests the load_data and preprocess_data functions.
