1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import log_artifact, pyfunc, traceback

def load_data(file_path):
    try:
        return pd.read_csv(file_path)
    except Exception as e:
        log_artifact(f"load_data_error.txt", "text/plain")
        open("load_data_error.txt", "w").write(traceback.format_exception(etype=e, value=e, tb=e.__traceback__))
        raise e

def preprocess_data(data):
    data.fillna(0, inplace=True)
    X = data.drop('Anomaly', axis=1)
    y = data['Anomaly']
    return X, y

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    model.fit(X_train, y_train)
    mlflow_model = pyfunc.PyFuncModel.from_sklearn(model)
    mlflow.sklearn.log_model(mlflow_model, "model")
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.7
      uses: actions/setup-python@v2
      with:
        python-version: 3.7

    - name: Install dependencies
      run: |
        pip install -r requirements.txt
        pip install mlflow==1.30.1 scikit-learn==1.0.2

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Log Model
      run: python pipeline.py

    - name: Log artifacts
      run: |
        mlflow logs --artifact air_quality_model
```

Make sure to create a `requirements.txt` file to list the required packages:

```

scikit-learn==1.0.2
```
