To create a production-ready CI/CD pipeline for a RandomForest congestion detector, we will follow these steps:

1. **Create the `pipeline.py` module** with functions to load data, preprocess it, and train the model.
2. **Create a `test_pipeline.py` file** using pytest to test the functions in `pipeline.py`.
3. **Create a GitHub Actions YAML** to automate the CI/CD pipeline.

### Step 1: Create the `pipeline.py` module

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestRegressor
from sklearn.metrics import mean_squared_error
import mlflow
import mlflow.sklearn

def load_data(file_path):
    """Load data from a CSV file."""
    try:
        data = pd.read_csv(file_path)
        return data
    except FileNotFoundError:
        raise ValueError(f"File not found: {file_path}")
    except pd.errors.EmptyDataError:
        raise ValueError("The file is empty or contains no data.")

def preprocess_data(data):
    """Preprocess the data."""
    try:
        # Convert 'IsHoliday' to binary
        data['IsHoliday'] = data['IsHoliday'].map({True: 1, False: 0})
        
        # Encode categorical variables
        data = pd.get_dummies(data, columns=['weather_main', 'DayOfWeek', 'Month'])
        
        # Split features and target
        X = data.drop('Congestion', axis=1)
        y = data['Congestion']
        
        return X, y
    except Exception as e:
        raise ValueError(f"Preprocessing error: {e}")

def train_model(X_train, y_train):
    """Train the model."""
    try:
        model = RandomForestRegressor(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log the model to MLflow
        mlflow.sklearn.log_model(model, "random_forest_model")
        
        return model
    except Exception as e:
        raise ValueError(f"Training error: {e}")
```

### Step 3: Create the GitHub Actions YAML

```yaml
name: MLOps Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Load and preprocess data
      run: |
        python pipeline.py

    - name: Train the model
      run: |
        python pipeline.py

    - name: Log model to MLflow
      run: |
        mlflow log-model --model-path random_forest_model --artifact-path model

    - name: Run tests
      run: |
        pytest test_pipeline.py
```
