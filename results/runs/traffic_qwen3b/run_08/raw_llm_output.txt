To create a production-ready CI/CD pipeline for a RandomForest congestion detector, we will follow these steps:

1. **Pipeline Module (`pipeline.py`)**: This module will handle data loading, preprocessing, model training, and saving.
2. **Test File (`test_pipeline.py`)**: This file will contain unit tests for the pipeline module.
3. **GitHub Actions YAML**: This file will define the CI/CD pipeline.

### Step 1: Pipeline Module (`pipeline.py`)

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import classification_report, confusion_matrix
import mlflow
import mlflow.sklearn
import logging

# Initialize logging
logging.basicConfig(level=logging.INFO)

def load_data(file_path):
    """Load data from a CSV file."""
    logging.info("Loading data from %s", file_path)
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        logging.error("Error loading data: %s", e)
        raise

def preprocess_data(data):
    """Preprocess data by splitting features and target."""
    logging.info("Preprocessing data")
    try:
        features = data.drop(columns=['Congestion'])
        target = data['Congestion']
        X_train, X_test, y_train, y_test = train_test_split(features, target, test_size=0.2, random_state=42)
        return X_train, X_test, y_train, y_test
    except Exception as e:
        logging.error("Error preprocessing data: %s", e)
        raise

def train_model(X_train, y_train):
    """Train a RandomForest model."""
    logging.info("Training model")
    try:
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        return model
    except Exception as e:
        logging.error("Error training model: %s", e)
        raise

def save_model(model, file_path):
    """Save the trained model."""
    logging.info("Saving model to %s", file_path)
    try:
        mlflow.sklearn.save_model(model, file_path)
        logging.info("Model saved successfully")
    except Exception as e:
        logging.error("Error saving model: %s", e)
        raise

def run_pipeline(file_path):
    """Run the entire pipeline."""
    try:
        data = load_data(file_path)
        X_train, X_test, y_train, y_test = preprocess_data(data)
        model = train_model(X_train, y_train)
        save_model(model, 'models/random_forest_congestion_detector.pkl')
        logging.info("Pipeline completed successfully")
    except Exception as e:
        logging.error("Pipeline failed: %s", e)
        raise
```

### Step 2: Test File (`test_pipeline.py`)

```python
import unittest
from pipeline import load_data, preprocess_data, train_model, save_model, run_pipeline

class TestPipeline(unittest.TestCase):
    def test_load_data(self):
        data = load_data('data/traffic.csv')
        self.assertIsNotNone(data)

    def test_preprocess_data(self):
        data = load_data('data/traffic.csv')
        X_train, X_test, y_train, y_test = preprocess_data(data)
        self.assertIsNotNone(X_train)
        self.assertIsNotNone(X_test)
        self.assertIsNotNone(y_train)
        self.assertIsNotNone(y_test)

    def test_train_model(self):
        data = load_data('data/traffic.csv')
        X_train, X_test, y_train, y_test = preprocess_data(data)
        model = train_model(X_train, y_train)
        self.assertIsNotNone(model)

    def test_save_model(self):
        data = load_data('data/traffic.csv')
        X_train, X_test, y_train, y_test = preprocess_data(data)
        model = train_model(X_train, y_train)
        save_model(model, 'models/random_forest_congestion_detector.pkl')

    def test_run_pipeline(self):
        try:
            run_pipeline('data/traffic.csv')
            self.assertTrue(True)
        except Exception as e:
            self.assertFalse(True, f"Pipeline failed: {e}")

if __name__ == '__main__':
    unittest.main()
```

### Step 3: GitHub Actions YAML (`.github/workflows/ci-cd.yml`)

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Run tests
      run: |
        pytest

    - name: MLflow tracking
      uses: mlflow/mlflow-actions@v0.12.0
      with:
        mlflow-endpoint: https://mlflow.example.com
        mlflow-token: ${{ secrets.MLFLOW_TOKEN }}
        experiment-name: traffic-congestion
        run-name: ${{ github.run_id }}
        python-version: '3.8'
        python-packages: 'pipeline'
```

### Notes:
- **MLflow**: This is used for tracking experiments and saving models.
- **Error Handling**: The pipeline includes error handling for data loading, preprocessing, model training, and saving.
- **GitHub Actions**: This workflow runs on every push to the `main` branch and includes steps for checking out the code, setting up Python, installing dependencies, running tests, and tracking the experiment using MLflow.

Make sure to replace `https://mlflow.example.com` and `MLFLOW_TOKEN` with your actual MLflow server URL and token. Also, ensure you have a `requirements.txt` file with the necessary dependencies.
