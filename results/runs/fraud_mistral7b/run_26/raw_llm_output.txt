3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test pipeline
      run: |
        pytest test_pipeline.py

    - name: Train and log model
      run: |
        python pipeline.py --file data/fraud.csv
```

This example uses GitHub Actions for the CI/CD pipeline. The pipeline.py file contains functions for loading data, preprocessing data, and training a RandomForest model. The test_pipeline.py file contains unit tests for the pipeline.py functions. The GitHub Actions YAML file sets up a workflow that runs on every push to the main branch, tests the pipeline, and trains and logs the model.

You can customize the preprocess_data function to include any necessary data preprocessing steps, and adjust the train_model function to handle model evaluation and hyperparameter tuning if needed.
