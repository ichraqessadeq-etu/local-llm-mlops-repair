3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Run tests
      run: pytest test_pipeline.py

    - name: Train model and log to MLflow
      run: python pipeline.py data/fraud.csv

    - name: Upload artifacts
      uses: actions/upload-artifact@v2
      with:
        name: model
        path: .mlflow/artifacts
```

This pipeline uses GitHub Actions to automate the build, test, and deployment process. The `build` job checks out the code, sets up Python, installs dependencies, runs tests, trains the model, logs the model to MLflow, and uploads the model artifact. The pipeline is triggered on every push and pull request.
