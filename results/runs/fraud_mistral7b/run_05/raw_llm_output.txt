3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test
      run: pytest

    - name: Train and log model
      run: |
        python pipeline.py --data data/fraud.csv --train 0.8
        mlflow log-artifact pipeline.py
        mlflow push --track-runs --source .
```

In this example, I've used MLflow to log the model and track runs. The `requirements.txt` file should contain the necessary dependencies for your project. You may also want to add additional steps for testing the model's performance on a validation set and handling errors appropriately.
