4. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install Dependencies
      run: |
        pip install -r requirements.txt

    - name: Test Pipeline
      run: |
        pytest test_pipeline.py

    - name: Train Model
      run: |
        python pipeline.py

    - name: Log Model
      run: |
        mlflow login --username $MLFLOW_USER --password $MLFLOW_PASS
        mlflow push artifact -t my-model
```

This setup includes a Python module for loading data, preprocessing, and training a Random Forest model using MLflow. The test suite verifies the functionality of the pipeline, and GitHub Actions automate the building, testing, and deployment of the model. Make sure to replace `$MLFLOW_USER` and `$MLFLOW_PASS` with your actual MLflow credentials.
