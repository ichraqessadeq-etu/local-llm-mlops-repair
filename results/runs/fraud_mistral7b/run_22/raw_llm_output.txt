3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: 3.8
      - name: Install dependencies
        run: |
          pip install pandas mlflow pytest
      - name: Test
        run: pytest test_pipeline.py
      - name: Train and Save Model
        run: python pipeline.py data/fraud.csv
      - name: Upload Model
        uses: mlflow/mlflow-action@v2
        with:
          track: True
          artifact_path: models
```

This setup uses MLflow for model training, saving, and versioning. Pytest is used for testing the pipeline. The GitHub Actions workflow runs on every push or pull request, ensuring the pipeline is always tested and the model is always up-to-date.
