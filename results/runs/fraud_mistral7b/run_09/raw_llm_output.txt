    return data, data['Amount']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "random-forest")

    return model

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up MLflow
      uses: mlflow/mlflow-docker@v1
      with:
        python: 3.8
        conda_env: mlflow_env
        mlflow_version: 1.21.0

    - name: Install dependencies
      run: pip install -r requirements.txt

    - name: Test pipeline
      run: pytest test_pipeline.py

    - name: Train and log model
      run: python pipeline.py data/fraud.csv

    - name: Deploy model
      uses: mlflow/mlflow-docker@v1
      with:
        python: 3.8
        conda_env: mlflow_env
        mlflow_version: 1.21.0
        command: mlflow deploy local --name random-forest-fraud-detector --package-path .
```

This CI/CD pipeline will run on every push and pull request. It sets up an MLflow environment, installs dependencies, runs tests, trains the model, and logs it using MLflow. After that, it deploys the model using MLflow. Make sure to create a `requirements.txt` file to list your project's dependencies.
