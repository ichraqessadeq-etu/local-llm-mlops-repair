3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.8
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas mlflow pytest

    - name: Test
      run: |
        pytest test_pipeline.py

    - name: Train and log model
      run: |
        python pipeline.py
```

This setup uses GitHub Actions to run tests and train the model on every push to the main branch. It also uses MLflow to track the runs and log the model. You can further customize the pipeline by adding more preprocessing steps, error handling, and model evaluation metrics.
