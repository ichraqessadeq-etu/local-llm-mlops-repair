def load_data(file_path):

def train_model(X_train, y_train):
    with start_run():

2. test_pipeline.py

```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def test_load_data(self):
        data = load_data("data/fraud.csv")
        self.assertIsInstance(data, pd.DataFrame)

    def test_preprocess_data(self):
        data, _ = preprocess_data(load_data("data/fraud.csv"))
        self.assertIsInstance(data, tuple)
        self.assertIsInstance(data[0], pd.DataFrame)
        self.assertIsInstance(data[1], pd.Series)

    def test_train_model(self):
        X, y = preprocess_data(load_data("data/fraud.csv"))
        model = train_model(X_train=X, y_train=y)
        self.assertIsInstance(model, RandomForestClassifier)

if __name__ == "__main__":
    unittest.main()
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install pandas numpy scikit-learn mlflow pytest

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and log model
      run: python pipeline.py --file data/fraud.csv

    - name: Upload artifacts
      uses: actions/upload-artifact@v2
      with:
        name: model
        path: mlruns/0/artifacts/random_forest
```

This pipeline uses MLflow to track the model and log parameters. It also includes unit tests for the pipeline functions and a GitHub Actions workflow for building, testing, and training the model. The workflow runs on every push and pull request to ensure the model stays up-to-date and functional.
