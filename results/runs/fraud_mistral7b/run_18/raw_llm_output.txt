3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    name: Build and Train Model
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up MLflow
      uses: mlflow/mlflow-docker@v1
      with:
        mlflow_version: 1.22.0
        python: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test Pipeline
      run: |
        pytest test_pipeline.py

    - name: Train Model
      run: |
        python pipeline.py
```

This setup uses GitHub Actions to automatically build, test, and train the model whenever changes are pushed to the `main` branch. The `requirements.txt` file should contain the necessary dependencies for your project. Make sure to adjust the MLflow version and Python version in the GitHub Actions YAML according to your needs.
