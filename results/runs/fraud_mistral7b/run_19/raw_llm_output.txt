1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
import mlflow
import mlflow.sklearn

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Data preprocessing steps such as handling missing values, encoding categorical variables, etc.
    # For simplicity, I'll assume no preprocessing is needed.
    return data['Features'], data['Class']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "random-forest")
    return model
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    name: Build and Test
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup Python
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test
      run: pytest test_pipeline.py

  train:
    name: Train Model
    needs: build
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Setup MLflow
      uses: mlflow/mlflow-docker@v1
      with:
        docker-image: mlflow/mlflow:1.22.0-python3.8

    - name: Train Model
      run: |
        python pipeline.py \
        --data data/fraud.csv \
        --features Features \
        --target Class \
        --model-path models/random-forest
```

This example assumes you have a requirements.txt file listing the necessary dependencies, and the MLflow Docker image is used for training the model. The pipeline.py file reads the data from the specified CSV file and trains a Random Forest model using MLflow for logging the model artifact. The GitHub Actions workflow consists of two jobs: one for building and testing the pipeline, and another for training the model. The trained model artifact will be saved in the "models/random-forest" directory.
