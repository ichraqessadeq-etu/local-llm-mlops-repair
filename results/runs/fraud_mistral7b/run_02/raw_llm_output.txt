1. pipeline.py

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from mlflow import PyFuncModel, log_model, log_artifact

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Add any necessary preprocessing steps here
    X = data.drop('Class', axis=1)
    y = data['Class']
    return X, y

def train_model(X_train, y_train):
    model = RandomForestClassifier()
    model.fit(X_train, y_train)
    return model

def save_model(model, model_name):
    with PyFuncModel.create_context() as ctx:
        model = PyFuncModel(model, input_schema=ctx.get_schema(X_train), output_schema=ctx.get_schema(y_train))
        log_model(model, "model", registered_model_name=model_name)
        log_artifact(model.model_uri, f"models/{model_name}")
```

3. GitHub Actions YAML

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up MLflow
      uses: mlflow/mlflow-docker@v1
      with:
        image: mlflow/mlflow:1.22.0-python3.8
        python: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test
      run: pytest test_pipeline.py

    - name: Train and Save Model
      run: |
        mlflow run --python pipeline.py --data data/fraud.csv --model random_forest_fraud_detector
```

This setup uses MLflow for model training, saving, and versioning. The GitHub Actions workflow is triggered on every push to the main branch. It sets up the MLflow environment, installs dependencies, runs the tests, trains the model, and saves it.
