```python
from mlflow import log_artifact, pyfunc, track

def load_data(file_path):
    return pd.read_csv(file_path)

def preprocess_data(data):
    # Add any necessary preprocessing steps here
    return data.drop('Amount', axis=1), data['Amount']

def train_model(X_train, y_train):
    with mlflow.start_run():
        model = RandomForestClassifier()
        model.fit(X_train, y_train)
        mlflow.pyfunc.log_model(model, "model")
        mlflow.log_artifact(artifact_path="model", artifact_rel_path="models")

        track(f"Training score: {model.score_}")
```

3. GitHub Actions YAML:

```yaml
name: CI/CD Pipeline

on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - uses: actions/checkout@v2

    - name: Set up Python 3.8
      uses: actions/setup-python@v2
      with:
        python-version: 3.8

    - name: Install dependencies
      run: |
        pip install -r requirements.txt

    - name: Test the pipeline
      run: pytest test_pipeline.py

    - name: Train and log model
      run: python pipeline.py

    - name: Upload artifacts
      uses: actions/upload-artifact@v2
      with:
        name: models
        path: mlruns/0/artifacts/models
```

This setup uses MLflow for model training, version control, and artifact management. Pytest is used for testing the pipeline, and GitHub Actions handle the CI/CD pipeline. The YAML file triggers the pipeline on every push or pull request.
