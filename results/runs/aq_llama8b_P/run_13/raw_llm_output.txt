Here is the code for the production-ready CI/CD pipeline for a RandomForest anomaly detector:

**pipeline.py**
```python
import pandas as pd
import numpy as np
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow.sklearn
import mlflow

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        mlflow.log_error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Scale features using StandardScaler
        scaler = StandardScaler()
        X = scaler.fit_transform(data.drop('Anomaly', axis=1))
        
        # Split data into features (X) and target (y)
        y = data['Anomaly']
        return X, y
    except Exception as e:
        mlflow.log_error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Train RandomForest classifier
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log model with MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        mlflow.log_error(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import pytest
from pipeline import load_data, preprocess_data, train_model

def test_load_data():
    data = load_data('data/air_quality.csv')
    assert data is not None

def test_preprocess_data():
    data = load_data('data/air_quality.csv')
    X, y = preprocess_data(data)
    assert X is not None
    assert y is not None

def test_train_model():
    data = load_data('data/air_quality.csv')
    X, y = preprocess_data(data)
    model = train_model(X, y)
    assert model is not None
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python environment
        uses: actions/setup-python@v2
        with:
          python-version: '3.7'

      - name: Install dependencies
        run: |
          pip install -r requirements.txt

      - name: Run tests
        run: |
          pytest test_pipeline.py

      - name: Train model
        run: |
          python pipeline.py --data data/air_quality.csv --output model.pkl

      - name: Log model with MLflow
        run: |
          mlflow ui

      - name: Deploy model
        uses: appleboy/ssh-action@v0.3.0
        with:
          host: ${{ secrets.HOST }}
          username: ${{ secrets.USERNAME }}
          password: ${{ secrets.PASSWORD }}
          script: |
            mkdir -p /path/to/model
            cp model.pkl /path/to/model/
```

**requirements.txt**
```bash
mlflow==1.30.1
scikit-learn==1.0.2
pandas==1.3.5
numpy==1.21.4
```

Note that you'll need to replace the `HOST`, `USERNAME`, and `PASSWORD` secrets in the GitHub Actions YAML with your actual deployment credentials.

Also, this pipeline assumes that the `air_quality.csv` file is located in the `data` directory, and that the `model.pkl` file will be deployed to the `/path/to/model` directory on the remote server. You'll need to adjust these paths as needed for your specific use case.
