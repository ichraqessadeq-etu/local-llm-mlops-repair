Here is the code for the CI/CD pipeline:

**pipeline.py**
```python
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
import mlflow.sklearn
import mlflow

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        mlflow.log_error(f"Error loading data: {e}")
        raise

def preprocess_data(data):
    try:
        # Drop unnecessary columns
        data.drop(['Hour', 'DayOfWeek', 'Month'], axis=1, inplace=True)
        
        # Scale features
        scaler = StandardScaler()
        X = scaler.fit_transform(data.drop('Anomaly', axis=1))
        
        # Encode target variable
        y = data['Anomaly'].map({'Normal': 0, 'Anomaly': 1})
        
        return X, y
    except Exception as e:
        mlflow.log_error(f"Error preprocessing data: {e}")
        raise

def train_model(X_train, y_train):
    try:
        # Train model
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log model to MLflow
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        mlflow.log_error(f"Error training model: {e}")
        raise
```

**test_pipeline.py**
```python
import unittest
from pipeline import load_data, preprocess_data, train_model

class TestPipeline(unittest.TestCase):
    def test_load_data(self):
        data = load_data('data/air_quality.csv')
        self.assertIsNotNone(data)
    
    def test_preprocess_data(self):
        data = load_data('data/air_quality.csv')
        X, y = preprocess_data(data)
        self.assertIsNotNone(X)
        self.assertIsNotNone(y)
    
    def test_train_model(self):
        data = load_data('data/air_quality.csv')
        X, y = preprocess_data(data)
        model = train_model(X, y)
        self.assertIsNotNone(model)
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2
        
      - name: Set up Python environment
        uses: actions/setup-python@v2
        with:
          python-version: '3.7'
        
      - name: Install dependencies
        run: |
          pip install -r requirements.txt
        
      - name: Run tests
        run: |
          pytest test_pipeline.py
        
      - name: Train model
        run: |
          python pipeline.py --file data/air_quality.csv
        
      - name: Log model to MLflow
        run: |
          mlflow run . --no-remote
        
      - name: Deploy model
        run: |
          # Deploy model to production environment
          # (e.g. using Kubernetes, Docker, etc.)
```

Note that this is just a basic example, and you may need to modify it to fit your specific use case. Additionally, you will need to create a production environment to deploy the model to.

Also, make sure to replace the `data/air_quality.csv` file with your actual data file.

This pipeline assumes that you have the `requirements.txt` file in the root of your repository, which lists the dependencies required to run the pipeline. The `github/workflows/ci_cd.yml` file defines the CI/CD pipeline, which runs on every push to the `main` branch. The pipeline consists of several steps:

1. Checkout code
2. Set up Python environment
3. Install dependencies
4. Run tests
5. Train model
6. Log model to MLflow
7. Deploy model to production environment

The `pytest` command is used to run the tests in the `test_pipeline.py` file. The `mlflow run` command is used to log the trained model to MLflow. The `deploy model` step is currently commented out, as it depends on your specific deployment environment.
