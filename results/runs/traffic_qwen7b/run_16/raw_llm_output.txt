### 1. Python Module: `pipeline.py`

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score
import mlflow
import mlflow.sklearn

def load_data(file_path):
    """Load data from a CSV file."""
    return pd.read_csv(file_path)

def preprocess_data(data):
    """Preprocess data to split into features and target."""
    X = data.drop(columns=['Congestion'])
    y = data['Congestion']
    return X, y

def train_model(X_train, y_train):
    """Train a RandomForestClassifier and log the model using MLflow."""
    with mlflow.start_run():
        mlflow.log_param("model", "RandomForestClassifier")
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        mlflow.sklearn.log_model(model, "model")
        y_pred = model.predict(X_train)
        accuracy = accuracy_score(y_train, y_pred)
        mlflow.log_metric("train_accuracy", accuracy)
        return model
```

```python
def test_train_model():

    X, y = preprocess_data(data)

```

### 3. GitHub Actions YAML: `.github/workflows/ci-cd.yml`

```yaml
name: CI/CD Pipeline

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
    - name: Checkout code
      uses: actions/checkout@v2

    - name: Set up Python
      uses: actions/setup-python@v2
      with:
        python-version: '3.8'

    - name: Install dependencies
      run: |
        python -m pip install --upgrade pip
        pip install pandas scikit-learn mlflow pytest

    - name: Run tests
      run: pytest

    - name: Train model and log to MLflow
      run: |
        python -c "from pipeline import load_data, preprocess_data, train_model; train_model(*preprocess_data(load_data('data/traffic.csv')))"
```

### Explanation:

1. **pipeline.py**:
   - `load_data`: Loads data from a CSV file.
   - `preprocess_data`: Splits the data into features (`X`) and target (`y`).
   - `train_model`: Trains a RandomForestClassifier and logs the model using MLflow.

2. **test_pipeline.py**:
   - Contains tests for loading data, preprocessing data, and training the model.

3. **GitHub Actions YAML**:
   - Triggers on push or pull request to the `main` branch.
   - Sets up a Python environment.
   - Installs dependencies.
   - Runs tests using `pytest`.
   - Trains the model and logs it to MLflow.
