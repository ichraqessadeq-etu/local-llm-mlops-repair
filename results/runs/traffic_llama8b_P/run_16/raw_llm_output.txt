Here is the code for the CI/CD pipeline:

**pipeline.py**
```python
import mlflow
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler

def load_data(file_path):
    try:
        data = pd.read_csv(file_path)
        return data
    except Exception as e:
        mlflow.log_error(f"Error loading data: {str(e)}")
        raise

def preprocess_data(data):
    try:
        # Convert categorical variables to numerical
        data['weather_main'] = data['weather_main'].map({'Clear': 0, 'Clouds': 1, 'Rain': 2, 'Snow': 3})
        data['Holiday'] = data['Holiday'].map({False: 0, True: 1})
        
        # Scale numerical features
        scaler = StandardScaler()
        data[['temp', 'rain_1h', 'snow_1h', 'clouds_all']] = scaler.fit_transform(data[['temp', 'rain_1h', 'snow_1h', 'clouds_all']])
        
        # Split data into features (X) and target (y)
        X = data.drop('Congestion', axis=1)
        y = data['Congestion']
        
        return X, y
    except Exception as e:
        mlflow.log_error(f"Error preprocessing data: {str(e)}")
        raise

def train_model(X_train, y_train):
    try:
        # Train a RandomForest classifier
        model = RandomForestClassifier(n_estimators=100, random_state=42)
        model.fit(X_train, y_train)
        
        # Log the model
        mlflow.sklearn.log_model(model, "random_forest")
        
        return model
    except Exception as e:
        mlflow.log_error(f"Error training model: {str(e)}")
        raise
```

**.github/workflows/ci_cd.yml**
```yml
name: CI/CD

on:
  push:
    branches:
      - main

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout code
        uses: actions/checkout@v2

      - name: Set up Python
        uses: actions/setup-python@v2
        with:
          python-version: '3.7'

      - name: Install dependencies
        run: |
          pip install -r requirements.txt

      - name: Train model
        run: |
          python pipeline.py

      - name: Test model
        run: |
          pytest test_pipeline.py

      - name: Deploy model
        uses: actions/checkout@v2
        run: |
          mlflow ui

      - name: Save model
        uses: actions/checkout@v2
        run: |
          mlflow save -m "Random Forest Congestion Detector"
```

**requirements.txt**
```bash
mlflow==1.30.1
scikit-learn==1.0.2
pandas==1.0.5
```

This pipeline assumes that the data is stored in a CSV file called `traffic.csv` in the `data` directory. The pipeline loads the data, preprocesses it, trains a RandomForest classifier, and logs the model using MLflow. The test pipeline checks that the data can be loaded, preprocessed, and the model can be trained. The CI/CD pipeline uses GitHub Actions to automate the build, test, and deployment of the model.

Note that this pipeline uses the `mlflow` command-line tool to log the model and save it to the MLflow tracking server. You will need to configure the MLflow tracking server and the `mlflow` command-line tool to use this pipeline.
